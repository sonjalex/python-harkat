# Pelin nimi

Sonja Okkola

Projektiin on luotu erillisiä luokkien kansioita ja niille oma pääohjelma

Pelin ideana on, että saat satunnaisesti yhden eläimen itsellesi josta sinun pitää pitää huolta.

Ensimmäinen tehtävä on ostaa ruokakaupasta sopivaa ruokaa

Kullekkin eläimelle sopivaa ruokaa ei ole vielä määritelty.

Projektin luokat toimivat moitteetta ilman valikko luokkaa, joka aiheuttaa TypeError virheen, en osaa tätä korjata nyt ja oletettavasti tarvitsen apua siihen myöhemmin.
